# BistroDefence

2023 Unity Game Project: Bistro Defence

게임 개요:

- VR 환경에서 작동

- 적들로부터 구역을 방어하는 디펜스 게임

- 플레이어는 총을 사용해 적들을 처치할 수 있음

- 적들은 매 라운드마다 정해진 수만큼 소환됨

- 각 적은 근거리 공격, 원거리 공격으로 나뉘어 있음

- 멀티플레이 지원

개발에서 수행 역할:

- 적들의 AI 개발

    - NavMesh를 통해 적들이 플레이어에 최단 거리로 이동하도록 설정

    - 적들이 플레이어를 향해 길을 찾을 때 겹치지 않도록 경로 탐색 알고리즘을 수정
 
- 적 엔티티의 애니메이션 적용

    - 근거리, 원거리 적에 따라 서로 다른 애니메이션과 모션 속도를 설정

    - 애니메이션을 텍스처 형태로 구현

        - 다수의 적들의 애니메이션이 성능 저하를 유발하므로 셰이더를 사용해 모션 정보를 담은 텍스처를 생성

        - 약 30% 정도의 성능 향상

- 투사체 물리 법칙 구현(날아가는 화살의 궤도 등)
